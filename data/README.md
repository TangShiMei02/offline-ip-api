# 数据库目录

这里存放 IP 归属地数据库，**文件不随仓库分发**，需要自己下载：

```bash
bash ../scripts/update_db.sh
```

下载完成后本目录下应该有两个文件：

| 文件 | 用途 | 大小 |
|---|---|---|
| `ip2region.db` | IPv4 查询 | 约 8.3 MB |
| `ipv6wry.db` | IPv6 查询 | 约 2.5 MB |

只保留其中一个也能跑：
- 只有 `ip2region.db` → IPv4 正常，IPv6 查询返回「无效或未收录」
- 只有 `ipv6wry.db` → IPv6 正常，IPv4 查询返回「无效或未收录」

服务启动时会把这两个文件**整个读进内存**，之后查询是纯内存二分。所以：

- 文件被替换（比如跑 `update_db.sh`）后，**服务会自动热重载，不需要重启**；
- **不要**用多进程 / 多 worker 启动服务，否则每个进程都会加载一份，内存翻倍。

数据来源与授权见项目根目录 README 的「数据来源与许可」一节。
